## Project Description

This project is a responsive workshop registration form developed using HTML, CSS and JavaScript.

The form allows users to:
- Select a workshop
- Enter their personal information
- Select a workshop date
- Specify the number of seats
- Enter and confirm a password
- Accept the registration agreement

JavaScript is used to perform custom validation and display a successful registration preview.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Files

- `index.html` – Contains the structure of the registration page.
- `styles.css` – Contains the styling and responsive layout.
- `app.js` – Contains the JavaScript functionality and validation.

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Project Purpose

The purpose of this project is to demonstrate practical understanding of HTML forms, CSS responsive design and JavaScript form validation.
